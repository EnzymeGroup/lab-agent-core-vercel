# Sequence summary project

Load the sequence-summary skill before analysis. The fixed `summarize` Python tool reads data/input.fasta and creates summary.json and report.md in the current run output directory. Preserve source headers, duplicate identifiers, sequence case and empty sequences. Ambiguous characters are observations, not errors to repair. Never invent biological function or wet-lab evidence. Core runs an independent checker after task execution; report execution and delivery separately.
